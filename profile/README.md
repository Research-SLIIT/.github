# Research-SLIIT

**Final Year Research Project — CSE-25-26J-445**

A research initiative focused on the **Colombo Stock Exchange (CSE)**, combining real-time market data processing, sentiment analysis, and intelligent insights to support data-driven investment decisions.

---

## Overview

This project explores the application of modern software engineering and machine learning techniques to stock market analysis in the Sri Lankan context. It is built as a full-stack system with a microservices backend and a modern web frontend.

## Repositories

| Repository | Description | Stack |
|------------|-------------|-------|
| [Backend](https://github.com/Research-SLIIT/Final-Year-Research_CSE-25-26J-445-Backend/tree/dev-deploy) | Microservices backend handling data ingestion, sentiment analysis, and API services | NestJS · Kafka · gRPC · FAISS |
| [Frontend](https://github.com/Research-SLIIT/Final-Year-Research_CSE-25-26J-445-Frontend/tree/dev) | Web application for visualising market data and insights | Next.js · TypeScript · Tailwind CSS · Zustand |

## Key Features

- Real-time stock market data processing
- Sentiment analysis on market-related content
- Vector-based similarity search for insights
- Event-driven microservices architecture
- Interactive, responsive dashboard

## Tech Stack

**Frontend:** Next.js, TypeScript, Tailwind CSS, Zustand
**Backend:** NestJS, Apache Kafka, gRPC, Git LFS (vector artifacts)
**ML / Data:** Sentiment analysis, FAISS vector search
